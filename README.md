# Красный контроль

Приложение для наблюдателей от КПРФ: материалы для подготовки, дорожная карта работы на участке, счётчик явки, подготовка жалоб и контакты штаба.

Текущая версия — **0.1.0**. Приложение написано на React Native и Expo для Android, iOS и веба. Материалы включаются в сборку, записи хранятся на устройстве. Сервер, авторизация и передача данных в штаб не подключены. Проверка на физических устройствах необходима перед рабочим распространением.

## Возможности

- **Выбор выборов и УИК.** Поиск по номеру, региону и адресу, дерево комиссий, просмотр дорожной карты и законов перед выбором. ФИО наблюдателя и подтверждённый участок сохраняются. Рабочие разделы требуют выбранных выборов и УИК.
- **Информация.** Библиотека с поиском: теория, документы и законы. Тексты, ссылки на правовые нормы, локальные оригиналы документов и видео определяются каталогом выбранной кампании. Неопубликованный оригинал недоступен.
- **Дорожная карта.** Выбор дня кампании, этапы и пункты с отметками выполнения, повторяемые этапы (в том числе выезды на надомное голосование), ссылки на нормы и заметки. Заметки сохраняются кнопкой «Сохранить».
- **Явка.** Кнопка «+1», отмена последнего добавления, исправление общего итога с обязательной причиной, отдельные сверки с данными комиссии, график и история. Итог накапливается за все дни выбранных выборов и участка; переключение дня не обнуляет его. Напоминания о сверках работают только в открытом приложении.
- **Жалобы.** Выбор одного нарушения, заполнение полей шаблона, обстоятельств и ФИО, формирование редактируемого текста, сохранение черновика и экспорт текста. Генератор использует шаблоны и правовые ссылки из каталога. Приложение не подписывает и не подаёт жалобы; заполненный DOCX или PDF не создаётся.
- **Мой участок.** Просмотр адреса и редактирование локального состава комиссии: ФИО, организация, добавление и удаление дополнительных членов.
- **Связь со штабом.** Опубликованные контакты и личные контакты для выбранных выборов и участка. Личные контакты можно добавлять, редактировать, удалять; звонок открывает приложение телефона.
- **Экспорт данных.** В окне выбора выборов доступен экспорт состояния в JSON, а при наличии старого архива — экспорт прежних данных. В вебе экспорт скачивает файл, на телефоне открывает системное меню отправки текста. Импорт резервной копии через интерфейс не реализован.

## Материалы в репозитории

Каталог сейчас содержит одну кампанию `deputy-2026` («Депутатские выборы 2026») со статусом `draft`, датами 18–20 сентября 2026 года и деревом комиссий Тюменской области. Контакты штаба пока не заполнены. Эти даты и сведения описывают содержимое проекта, а не подтверждённое расписание выборов. Инструкции и правовые ссылки требуют редакторской проверки для конкретной кампании.

Исходные данные хранятся в **YAML**. Перед запуском и сборкой они проверяются и преобразуются в каталог приложения; на устройстве YAML не разбирается.

| Путь | Назначение |
| --- | --- |
| `src/content/catalog-manifest.yaml` | Список кампаний и ревизия каталога |
| `src/content/elections/<id>/manifest.yaml` | Название, даты и подборка материалов кампании |
| `src/content/elections/<id>/commissions.yaml` | Иерархия комиссий и участки |
| `src/content/elections/<id>/complaints.yaml` | Нарушения, шаблоны жалоб и правовые ссылки |
| `src/content/global/` | Общие темы, задачи, этапы, маршруты, контакты и настройки |
| `src/content/global/laws/laws.yaml` | Правовые нормы |
| `src/content/global/documents/`, `src/content/global/videos/` | Оригиналы документов, видео и их регистрации |
| `examples/authoring/` | Пример добавления собственной кампании |

После изменения YAML выполните `npm run build:content` и `npm run check:content`. Сгенерированные файлы `*.generated.*` вручную не редактируются. При обновлении действующей кампании сохраняйте идентификаторы, к которым привязаны записи наблюдателей.

Подробные примеры: [руководство по наполнению](docs/content-authoring-tutorial.md), [описание сборки каталога](docs/offline-authoring.md). Более старые архитектурные документы могут описывать предыдущие версии проекта.

## Запуск

Используйте Node.js 24 и npm. Зависимости зафиксированы в `package-lock.json`: Expo SDK 57, React Native 0.86.3, React 19.2.3 и TypeScript.

```sh
npm ci
npm run web
```

Веб-версия доступна на `http://localhost:8081`. Другие команды:

```sh
npm start          # сервер разработки Expo
npm run android   # сборка и запуск нативного Android-приложения
npm run ios       # сборка и запуск нативного iOS-приложения (macOS)
```

Для Android нужны Android SDK и соответствующее окружение сборки; для iOS — macOS и Xcode. Совместимость клиента Expo Go с SDK проекта нужно учитывать отдельно.

## Проверки и сборки

```sh
npm run check:content
npm run check:example
npm run typecheck
npm test
npm run test:integration
npm run build:web
npm run build:mobile
```

`npm test` проверяет модель данных, миграции, каталог, жалобы и явку. Интеграционные тесты проверяют сценарии интерфейса. `build:web` создаёт веб-сборку в `dist/`; `build:mobile` экспортирует ресурсы Android и iOS в `dist-native/` и **не создаёт APK или IPA**.

Для браузерных сценариев сначала выполните `npm run build:web`, запустите `npm run preview` (порт 8082), затем в другом терминале — `npm run test:e2e`. При первом использовании Cypress может потребоваться `npx cypress install`.

В `eas.json` настроены профили Android: `preview` для APK и `production` для AAB. Сборка через EAS требует доступа к проекту Expo и настройки подписи:

```sh
npx eas-cli build --platform android --profile preview
npx eas-cli build --platform android --profile production
```

Идентификатор приложения — `ru.redcontrol.observer`. Публикация в магазинах автоматически не настроена.

## Хранение и ограничения

На Android и iOS состояние хранится атомарным снимком в SQLite (`red-control.db`); в вебе — в `localStorage`. Используется схема данных версии 4 с миграциями предыдущих форматов. Записи разделяются по выборам и участкам, сохраняются после перезапуска и смены выбранного контекста. Очередь изменений локальная: действующего отправителя на сервер нет.

Включённые в сборку материалы и сохранённые записи доступны без сети в установленном приложении. Первый запуск веб-версии требует загрузки сайта; установка PWA и автономное кеширование сайта не настроены. Открытие отдельных файлов и звонки зависят от возможностей устройства.

Счётчики разных наблюдателей не объединяются. JSON-экспорт не включает двоичные вложения и не заменяет проверенное восстановление данных. Очистка данных приложения или браузера удаляет локальные записи.

Перед распространением проверьте материалы, даты, контакты, работу без сети, открытие вложений, экспорт и обновление приложения с сохранением записей на реальных телефонах. Автоматические проверки не подтверждают готовность к полевой работе.

Отдельная лицензия на код и материалы в репозитории пока не задана.
