# Проверки и сценарии приложения

## Единая проверка

Требуются Node.js 24 и зависимости из `package-lock.json`:

```sh
npm ci
npm run check
```

Команда проверяет актуальность каталога, типы TypeScript, тесты Node и сценарии Jest с измерением покрытия. В GitHub Actions дополнительно проверяются веб-сборка, экспорт ресурсов Android/iOS и браузерные сценарии Cypress.

```sh
npm test                  # логика, миграции, каталог и исходные материалы
npm run test:integration  # интерфейс, контроллеры и платформенные адаптеры
npm run test:coverage     # те же сценарии Jest с отчётом покрытия
npm run build:web
npm run preview
# В другом терминале:
npm run test:e2e
```

Отчёт покрытия: `coverage/index.html`; машинный результат: `coverage/coverage-summary.json`. Отчёты исключены из Git. Порог Jest: строки и операторы — 70%, ветви — 60%, функции — 68%. Это защита от регрессии измеримого покрытия, а не заявление о полном покрытии приложения.

В измерение входят все исполняемые TypeScript-модули в `src/`, в том числе не открытые тестами экраны. Исключены автоматически сгенерированные регистрации ресурсов и файл деклараций типов. Тесты Node выполняются отдельно и не учитываются в процентах Jest. Проценты двух систем нельзя складывать.

## Что проверяется на устройствах

Моки SQLite, системного меню, проигрывателя и Android Intent подтверждают вызовы адаптеров, но не поведение операционной системы. Перед выпуском выполните на Android и iOS:

1. Запустите установленное приложение без сети; откройте инструкции, документы и видео.
2. Выберите УИК, добавьте явку, заметку, контакт и жалобу; перезапустите приложение.
3. Смените участок и вернитесь: записи должны оставаться раздельными.
4. Откройте DOCX/PDF в установленном просмотрщике; скопируйте текст жалобы и экспортируйте резервную копию.
5. Переведите приложение в фон во время видео; проверьте остановку воспроизведения.
6. Проверьте обновление установленной версии с существующими данными.
7. Проверьте доступность элементов с экранным диктором, крупным шрифтом и на узком экране.

Экспорт мобильных ресурсов не является сборкой APK/IPA и не заменяет эту проверку. Веб-приложение не имеет автономного кеша PWA; браузерный тест с перезагрузкой проверяет сохранение записей, а не запуск сайта без сети.
